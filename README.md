# AI Catchup

**一人ひとりの当たり前を、みんなの当たり前に。**

人とのつながりとAIを通じて、みんなが「自分にも、もっとできる」と感じられる場をつくります。

知らなかったことを知り、誰かと試し、昨日までできなかったことができるようになる。その積み重ねで、自分の可能性や生活が広がっていく。主催者自身がコミュニティで経験したことを、みんなにも体験してほしいし、自分も感じ続けたい。それが、この会を開く理由です。

CodexやOpenAIを軸に、新機能、普段の使い方、作ったもの、試して分かったこと、まだ分からないことを持ち寄ります。自分の当たり前が、誰かの発見になります。主催者も一緒に学びます。

聞く、話す、質問する、試す、発表する。関わり方は自由です。気になった卓へ移って、初めて会う人とも話してみてください。発表やGitHubへの投稿は任意です。

## 共通のビジョンと方針

| 読みたいこと | 正本 |
| --- | --- |
| 何のために集まり、何を大切にするか | [VISION.md](VISION.md) |
| 迷ったときの判断、方針の変更、問題への対応 | [POLICY.md](POLICY.md) |
| 発表・活用事例の投稿、PRの出し方 | [CONTRIBUTING.md](CONTRIBUTING.md) |

継続する方針は、このリポジトリの `main` にコミットされた文書へ集約します。各回では方針のコピーを作らず、この正本を参照します。変更の理由と合意はPRでたどれます。

スライド、記事、コード、デモが別の場所にあっても、URLと一言から投稿できます。発表していない人の「私はこう使った」「ここで困った」も歓迎します。PRに慣れていなければ、各回の投稿フォームを使ってください。

元の資料・投稿者・試した条件を残し、次の人がたどって試せる形で蓄積します。AIによる整理や紹介も、その原典を参照して育てていきます。

知見を共有し、交流や友情、新しいものづくりにつなげる。自分たちのために、みんなで楽しみながら続けるコミュニティです。この「自分たち」には、すべてのメンバーが含まれます。
